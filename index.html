03 // RUST KERNEL ARCHITECTURE (TOONTALKER-CORE) ICCV 2023 CROSS-DOMAIN REENACTMENT

01 // Domain-Adaptive Scaling

Compensates for exaggerated cartoon and anime eye/mouth proportions via `ArtisticDomain::motion_scale_factor` and domain-specific occlusion thresholds (`occlusion_threshold`). 

let scale = ArtisticDomain::Anime
    .motion_scale_factor(); // 1.25x
let transfer = MotionTransfer::new(
    ArtisticDomain::Anime, true, true);

02 // 2×2 Local Affine Jacobians

Each canonical keypoint carries a $2 \times 2$ local Jacobian $[j_{00}, j_{01}, j_{10}, j_{11}]$ modeling local tilt, scale, and mouth articulation shear (`transform_local_offset`). 

let aligned = transfer
    .cross_domain_transformer_align(
        &source_kp, &driving_kp);

03 // Dense RBF Flow & Occlusion

Interpolates sparse keypoint displacements into a $256 \times 256$ dense optical flow grid `(dx, dy)` and derives visibility confidence masks from flow magnitude gradients. 

let gen = DenseMotionGenerator::new(256);
let field = gen.compute_motion_field(
    &source_kp, &target_kp);
